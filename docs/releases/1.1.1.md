Mimamori 1.1.1 is a safety release. A maintainability review of 1.1.0 found a few ways Mimamori could lose your saved state, step on other tools' config files, or write to a worktree at the wrong moment, and this release fixes them all.

## Install or update

- **Already running Mimamori?** It offers this update itself (Mimamori › Check for Updates…).
- **New here?** Download **Mimamori-1.1.1.dmg** below, open it and drag **Mimamori** to **Applications**. It's signed with a Developer ID and notarized by Apple. Or run `brew install --cask cocoabeans/tap/mimamori`.

Requires macOS 15 or later, on Apple silicon or Intel, and `git`.

## Your saved state is safe

- **Mimamori no longer starts over when it can't read its state file.** Before, any problem reading `state.json` gave you an empty Mimamori, and the next save wrote that over your repositories, review marks and notes. Now it opens what it can, or the state as it was one save earlier, and keeps a copy of the file aside.
- **It tells you when that happens.** A notice at launch says what it did, and **Show in Finder** selects the copy it kept.

## Other tools' config files are edited with care

When you connect Claude Code or Hermes, Mimamori now:
- keeps `settings.json` exactly as you laid it out, changing only its own hooks;
- leaves a symlinked config file a symlink, and keeps the file's permissions;
- leaves a file it can't read or parse alone, and tells you why;
- gives every backup its own name, and never deletes the first one.

## Fixes

- **Permission requests from subagents.** With two subagents at work in one session, one finishing a tool call no longer drops the other's waiting request, along with its **Allow** and **Deny**.
- **Discard waits for the agent.** Discarding a hunk or a file, and undoing a discard, is refused while an agent is mid-turn in that worktree, however it's asked for.
- **Snapshots and refreshes take turns.** Marking the start or taking a snapshot while a refresh runs, such as right after you add a large repository, no longer fails with "index.lock: File exists".
- **Removing a repository mid-scan** no longer risks a crash, or another repository getting its worktrees.
- **Typing a note** no longer redraws the whole diff.
- **The Agents window's cards** keep up with the window when you resize it across two columns.
- **An ended agent counts once.** An agent whose session ended while its process kept running no longer shows as two agents in the menu bar and the sidebar.

## Removed

- Mimamori no longer looks for files from Vigil, its name before 1.0, at launch.
