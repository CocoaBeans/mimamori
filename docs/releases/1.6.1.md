Mimamori 1.6.1 keeps tooltips up while your agents work, and fixes a handful of small things in the diff and the Agents window.

## Install or update

- **Already running Mimamori?** It offers this update itself (Mimamori › Check for Updates…).
- **New here?** Download **Mimamori-1.6.1.dmg** below, open it and drag **Mimamori** to **Applications**. It's signed with a Developer ID and notarized by Apple. Or run `brew install --cask cocoabeans/tap/mimamori`.

Requires macOS 15 or later, on Apple silicon or Intel, and `git`.

## Fixes

- **Tooltips stay up.** While an agent worked, tooltips in the main window, such as those on the diff's buttons, vanished after a fraction of a second. The agent status in the toolbar rebuilt the toolbar each time its timer ticked; now it doesn't, and tooltips stay until you move away.
- **Discard buttons stay put.** While an agent edits the file whose diff is open, each hunk's **Discard…** button stays in place, disabled for a moment until the new diff loads, instead of vanishing and coming back.
- **Less redrawing.** The open diff no longer draws itself a second time after each load, or each time an agent's edit makes Mimamori reread a worktree where you've reviewed files or written notes.
- **Answers you've started choosing are kept.** When an agent asks you questions, the answers you've picked stay picked when you turn **Details** on or off in the Agents window, or close a window and open it again, and they read the same in the Agents window and the worktree's banner.
- **Image diffs.** Picking another changed image while a large one is still loading no longer shows the first one's before and after under the second one's name.
- **Jump to a flagged line, again.** Clicking a flag's line link scrolls to that line every time, not only the first.

## Your iPhone

- **Building the iPhone app yourself.** Help and the README now walk through building Mimamori Companion with Xcode and installing it on your iPhone, which adds staying connected in the background and the Live Activity. The App Store version needs nothing new for this release.
