Mimamori 1.2.0 follows Claude Code's subagents and the commands it runs in the background, lets an agent sleep between turns, and gets ready for an iPhone companion. It's also much lighter: with agents busy, Mimamori uses far less CPU than before.

## Install or update

- **Already running Mimamori?** It offers this update itself (Mimamori › Check for Updates…).
- **New here?** Download **Mimamori-1.2.0.dmg** below, open it and drag **Mimamori** to **Applications**. It's signed with a Developer ID and notarized by Apple. Or run `brew install --cask cocoabeans/tap/mimamori`.

Requires macOS 15 or later, on Apple silicon or Intel, and `git`.

## Subagents and background commands

- **An agent stays at work while its subagents do.** When Claude Code hands work to subagents, its agent stays in Working, "waiting on 2 subagents", and "finished a turn" waits for the last one.
- **See each subagent.** The agent's card in the Agents window, and its banner above the diff, list each subagent: its kind, what it was asked, its steps and time, and its latest step.
- **A subagent in a worktree of its own** stays on its parent's card, with its worktree a click away, rather than moving the parent's card back and forth.
- **Commands run in the background** show under the subagents, with how long each has run and how it ended. The agent reads "ready · 2 running in the background", since it's free for you meanwhile.

## Put an agent to sleep

Mimamori can stop an agent's process between turns and keep its session. **Wake** opens a terminal in the worktree that resumes it. For Claude Code and Codex, off until you turn it on in Settings › General.

## Your agents on your iPhone

- **Pair an iPhone** in the new Settings › iPhone by scanning a code with its Camera. On the same network, it shows your agents as the Agents window does. Each iPhone connects encrypted, with a key of its own, and proves which pairing it is.
- **On the iPhone:**
  - notifications when an agent needs you, finishes a turn or collides with another;
  - Allow or Deny for Claude Code's permission requests, with Face ID before Allow;
  - each agent's list of actions, with its subagents and background commands.
- **Off until you turn it on.** The iPhone app isn't in the App Store yet: for now it's built from source, from `Sources/MimamoriCompanion` in the same project.

## Lighter on energy

- **Closed windows stop redrawing.** A closed main window, Agents window or pinned overview no longer redraws while agents work. With three agents busy and only the menu bar showing, Mimamori uses about two thirds less CPU.
- **Faster git.** With git from Xcode or its Command Line Tools, Mimamori runs it directly instead of through `/usr/bin/git`. Each git command takes about 60% less CPU.
- **A shorter animation.** Cards in the Agents window move to their new place in a brief ease-out rather than a long spring, which saves about a fifth of the CPU with three agents at work.

## Fixes

- **Ask rules see the whole command.** Answering by itself checked only a command's first 8000 characters against your Claude Code ask rules, so a rule about its end could be missed. Now it checks the whole command, up to 64 KB, and a longer one waits for you.
- **No secrets in summaries.** A tool Mimamori doesn't know is described by a harmless field, never by its content or anything named like a token, password or key.
- **One agent, not two.** A script run with Python, Node or the like no longer shows as a second agent in its worktree because one of its arguments mentions an agent, such as a path through a folder named `claude-profiles`.
- **One Hermes session, not two.** A Hermes session that edits files from `execute_code` no longer shows as a second session, warning that "Two Hermes sessions" edited a file.
- **Wrapped diffs keep responding.** A diff with wrapped lines could stop responding right after a click on Reviewed, while an agent was editing the file. Wrapped diffs of up to 300 lines are now laid out in full, so their layout can't go round in circles.
