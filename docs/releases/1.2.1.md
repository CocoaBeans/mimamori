Mimamori 1.2.1 fixes how Hermes's permission requests show: no more false alarms while Hermes checks a command by itself, and no more requests that never showed at all.

## Install or update

- **Already running Mimamori?** It offers this update itself (Mimamori › Check for Updates…).
- **New here?** Download **Mimamori-1.2.1.dmg** below, open it and drag **Mimamori** to **Applications**. It's signed with a Developer ID and notarized by Apple. Or run `brew install --cask cocoabeans/tap/mimamori`.

Requires macOS 15 or later, on Apple silicon or Intel, and `git`.

## Fixes

- **No false "needs permission" from Hermes.** With Hermes's smart approvals on, Hermes has a second model check a risky command before it asks you, and it reports that check as an approval request. Mimamori showed Hermes as needing permission until the check passed, a few seconds later. Now Hermes stays Working through the check, and shows as needing permission only when the decision comes to you.
- **Hermes's requests from `execute_code` show up.** A command Hermes ran from inside `execute_code` asked for permission without saying which session it came from, so Mimamori couldn't place the request and dropped it. Hermes could be waiting on you with nothing showing. Mimamori now finds the session from Hermes's own records, shows the request on that session's card with the command it's about, and clears it once you answer.
- **The tool is named.** A Hermes permission request now says which tool it's for, such as "needs permission for terminal", instead of "a tool".
