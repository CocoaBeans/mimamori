Mimamori 1.3.0 answers Claude's questions on your Mac and your iPhone, shows a changed image as pictures, and names each Claude Code session, so you can tell which one is asking.

## Install or update

- **Already running Mimamori?** It offers this update itself (Mimamori › Check for Updates…).
- **New here?** Download **Mimamori-1.3.0.dmg** below, open it and drag **Mimamori** to **Applications**. It's signed with a Developer ID and notarized by Apple. Or run `brew install --cask cocoabeans/tap/mimamori`.

Requires macOS 15 or later, on Apple silicon or Intel, and `git`.

## Answer Claude's questions

- **On the card.** When Claude asks you one or several questions, each with options, the agent's card shows them in place of Allow and Deny. You'll see them in its banner, the toolbar's popover and the Agents window.
  - Choose an option for each question, or several where it allows, or write your own answer.
  - Then **Answer**: Mimamori hands your answers to Claude, as answering in its own prompt would.
- **On your iPhone.** A paired iPhone shows the same questions on the agent's card. **Answer** asks for Face ID or your passcode first, as Allow does, since an answer can set off as much.
- **A question stays a question.** The agent reads "asks: …" rather than "needs permission", Mimamori never answers a question by itself, and you get one notification for it, not two.

## Tell sessions apart

- **Session titles.** A Claude Code session now shows its title, as the Claude desktop app does: "Claude Code · Weekly disk cleanup check". You'll see it on its card, in the banner and in a permission notification.
  - So when several sessions work in one folder, a request names the session that's asking.
  - It's the title you gave the session, or else the one Claude Code chose.

## See a changed image

- **Before and after.** A changed image (PNG, JPEG, GIF, HEIC, TIFF, WebP and the other types macOS reads) shows as pictures in the diff, side by side, each with its size in pixels and bytes, over a checkerboard where it's transparent.
- An added or deleted image shows its one side. Other binary files still say only that they changed.

## Permission requests

- **Dismiss.** Beside Allow and Deny, **Dismiss** takes them away without answering, to answer in the agent's own prompt instead. The card then says "needs permission in its own prompt".
- **The Claude desktop app's own buttons work.** In the desktop app, Claude Code can wait for Mimamori's answer before its own Allow and Deny count. Mimamori now holds a request from the desktop app for 20 seconds, then leaves it to the app.
- **No dead buttons.** When Mimamori stops holding a request, its Allow and Deny go, rather than staying on screen with no effect.

## Fixes

- **Tapping an iPhone notification** opens the app again, instead of closing it.
