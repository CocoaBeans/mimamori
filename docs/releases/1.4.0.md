Mimamori 1.4.0 watches more agents: OMP, pi and Qwen Code now report what they're doing, and any other agent can set itself up from a prompt you paste. Hermes sessions also stay on their cards between turns.

## Install or update

- **Already running Mimamori?** It offers this update itself (Mimamori › Check for Updates…).
- **New here?** Download **Mimamori-1.4.0.dmg** below, open it and drag **Mimamori** to **Applications**. It's signed with a Developer ID and notarized by Apple. Or run `brew install --cask cocoabeans/tap/mimamori`.

Requires macOS 15 or later, on Apple silicon or Intel, and `git`.

## More agents

Each has a setup in **Settings › Agents › Other Agents** with a Copy button, and once it's in place, the agent's card shows its turns, its steps and the files it edits. **Heard from**, in the same pane, shows the setup working. Mimamori never edits these files itself.

- **OMP (oh-my-pi) and pi.** Their hooks are TypeScript extensions, so the setup is a small extension to save as `~/.omp/agent/extensions/mimamori.ts` or `~/.pi/agent/extensions/mimamori.ts`.
  - It sends what a step does, such as a file's path or a command, never a file's contents.
  - It gives up on an event after a second, so the agent never waits on Mimamori.
  - OMP's permission requests, questions and subagents show too.
  - The agent loads it when it starts. For OMP inside another app, such as Orca's chats, start that app's OMP again.
- **Qwen Code.** Hooks to add to `~/.qwen/settings.json`, beside any it already has. Its questions show on the card, as Claude's do.
- **Recognized without any setup.** Mimamori now spots a running OMP, pi or Qwen Code, and shows it in the worktree it works in.

## Let an agent connect itself

- **Copy Prompt.** Under **Or have your agent set this up**, Copy Prompt copies instructions to paste into the agent, which then sets up its own hooks.
  - For Codex, Gemini CLI, Cursor, Qwen Code, pi and OMP, the prompt carries the same setup the pane shows and says where it goes.
  - For any other agent, it describes the events Mimamori takes, so the agent can find its own hooks and connect them.
- **It plays it safe.** The prompt asks the agent to keep what its settings already hold, back them up first, never block on Mimamori or send file contents, check that Mimamori answers, and tell you what it changed.

## Fixes

- **Hermes sessions stay on their cards.** A Hermes session no longer reads as ended after each turn and drops off its card two minutes later; it stays, ready for your next prompt. Mimamori also recognizes Hermes's newer launcher again.
- **The iPhone's agent cards.** For the companion you build onto your iPhone:
  - the card at the top of an agent's actions no longer grows a tall empty band around its timeline;
  - its corners and border are no longer cut off by the list around it.
