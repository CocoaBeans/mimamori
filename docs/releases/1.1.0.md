Mimamori 1.1.0 lets you talk back to your agents from the diff, and throw away a change you don't want. It also fixes the case where Mimamori quietly stopped hearing from your agents.

## Install or update

- **Already running Mimamori?** It offers this update itself (Mimamori › Check for Updates…).
- **New here?** Download **Mimamori-1.1.0.dmg** below, open it and drag **Mimamori** to **Applications**. It's signed with a Developer ID and notarized by Apple. Or run `brew install --cask cocoabeans/tap/mimamori`.

Requires macOS 15 or later, on Apple silicon or Intel, and `git`.

## What's new

- **Review notes for the agent.** Hover over a line in a diff and click the bubble in its gutter to leave a note. Shift-click another line's bubble to cover the lines between, or add a note on the whole file from the bubble menu in the diff's header. Notes work on removed lines too, in one column or side by side.
  - A note quotes its lines and follows them as the file changes. Once they're gone, it moves above the diff with the code it was written on.
  - **Copy as Prompt** in the same menu copies this file's notes, or every unsent note in the worktree, as one prompt to paste where you talk to the agent.
  - The file list and the sidebar count the notes you haven't sent. Resolve a note once it's dealt with.
- **Discard a hunk or a whole file, if you let it.** Turn on **Settings › General › Working tree › Offer discarding hunks and files**. Then an *Uncommitted* diff has **Discard…** on each hunk and **Discard File…** in its header, and the file list's context menu has **Discard Changes…**. Each one shows what goes and asks first. It won't run while an agent is mid-turn in that worktree, and it checks that the file still matches the diff. It takes a snapshot first, so **Undo** can put it back.
- **Agents grouped in the menu bar.** The menu-bar popover now sorts agents under **Needs you**, **Working**, **Ready** and **Ended**, as the Agents window does. Fold any group away by its heading.
- **A turn already running when Mimamori starts shows its real start.** Mimamori reads this from Claude Code's session file and from Hermes's record of running turns, without reading any prompts or files. A Hermes turn under way shows as working from launch.

## Fixes

- **Mimamori no longer goes deaf to your agents when a second copy opens.** Every copy listens at the same hook socket, and a copy that opened briefly, such as an older one in Applications, took the socket and left the running copy hearing nothing. Agents then showed as "running, idle" while they worked. Now a copy doesn't take a socket that another copy is answering, and it takes the socket back once the other copy quits. Settings › Agents › Hooks › Socket says which copy has it.
- **Diffs of files with Windows line endings** now show line by line, with their colours and line numbers. Before, such a file showed as one long line and could hide the next file in the diff.

## Privacy

Mimamori still has no telemetry, and its one network request is still the update check. It stays read-only unless you turn on discarding. Even then it changes only the file you discard from, and only after you confirm, and it never touches the index.
