Mimamori

見守りmee-mah-MOH-ree

A lightweight mac app that keeps watch over git worktrees while coding agents work.

It sits beside Claude Code, Codex, Cursor or whatever you run, and answers two questions at a glance: what is it doing right now, and should I be worried?

見守り

Watching over, with care

Mimamori is Japanese for watching over someone with care: the way you watch children at play, ready to step in.

That is the job when an agent edits on your behalf. You don't need a git client built for committing. You need something that refreshes by itself, shows what changed in the last minute, keeps the whole session in view after the agent commits, and points out the few changes that deserve a human look.

What it does

Add a repository and Mimamori finds its worktrees, including the ones agent tools create, and watches them all.

Watches live

Changes appear a few hundred milliseconds after files settle. Recently touched files glow and say “12s ago”, so you can see where the agent is working.

Knows where the agents are

It shows which worktree each agent is in and, with hooks connected, each tool call, when a turn ends, and when one needs your permission.

Follows subagents

When Claude Code hands work to subagents, its card stays at work until the last one finishes, and lists each with its task and latest step. Commands left running in the background show too.

Flags what deserves a look

Secrets and .env files, lockfiles, CI and agent instruction files, skipped or deleted tests, mass deletions, conflict markers, and edits outside your scope.

Compares against the right baseline

Agents commit as they go. See what's uncommitted, everything since the branch point, since you pressed Mark Start, or since any earlier snapshot.

Remembers what you've reviewed

Mark files reviewed as you read them. When an agent edits one again, it comes back as changed since your review, with just the new edits.

Takes review notes for the agent

Leave a note on a line, a range of lines or a whole file. Notes follow their code as the file changes, and Copy as Prompt hands them to the agent in one go.

Answers permission requests

When Claude Code asks to run something, allow or deny it from Mimamori: the agent's banner, the Agents window or a notification. When Claude asks you questions, answer them right on its card.

Reaches your iPhone

Pair an iPhone on the same network to see your agents there, hear when one needs you, and allow, deny or answer its questions with Face ID. Encrypted, and off until you turn it on. The iPhone app is built from source for now.

Throws a change away, if you let it

Discard a hunk or a whole file from an uncommitted diff. It's off until you turn it on, waits while an agent is mid-turn, and keeps a snapshot so Undo can put it back.

Puts idle agents to sleep

An agent waiting for your next prompt still holds hundreds of megabytes. Put Claude Code or Codex to sleep between turns, and Wake resumes its session in your terminal.

Writes up a session

A Markdown summary of what changed, what needs attention, the commits and what the agent did, ready for a pull request or a handoff note.

Every agent, at a glance

The Agents window lists each worktree with an agent in it, grouped under Needs you, Working, Ready and Ended. Each card shows the agent's task, its latest steps, the files it touched, and a strip of its tool calls over time. The menu bar's popover groups them the same way, and a desktop widget keeps the one that needs you in view. A paired iPhone shows them too.

Read-only by default, and private

Mimamori can watch any repository while another tool is busy in it, because it never gets in the way.

  • Leaves your work alone. It never stages, commits, checks out or takes the repository's index.lock. Your branches and index stay as they are, and so does your code, unless you turn on discarding a hunk or a file.
  • Stays on your Mac. No account and no telemetry. Agents reach it through a socket only your own processes can use. If you pair an iPhone, Mimamori talks to it over your own network, encrypted with a key that phone alone holds; it's off until you turn it on.
  • Automatic updates. Official release builds ask GitHub for the list of releases when you check for updates, or once a day if you agree. Nothing about you or your Mac goes with it.
  • Open source. MIT licensed, so you can read every line or build it yourself.

Install

Mimamori needs macOS 15 or later and a git binary. It runs natively on Apple silicon and Intel and keeps itself up to date.

Homebrew

brew install --cask cocoabeans/tap/mimamori

Download

Get the latest release, open the disk image, and drag Mimamori to Applications. It's signed with a Developer ID and notarized by Apple.

The first time it opens, a welcome window explains what it reads and writes before anything is installed.
